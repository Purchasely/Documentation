Version 5.0 of the Purchasely SDK introduces support for the new [Screen Composer](https://docs.purchasely.com/docs/screen-composer) and includes several major updates and breaking changes.

Changelog per platform is available on their GitHub repositories.\
You can access them by clicking on the version number.

## New features

* Support of our new [Screen Composer](https://docs.purchasely.com/docs/screen-composer)
* Ability to set an array for a user attribute. The array must be of type String, Integer, Float or Boolean.
* Add 2 built-ins user attributes to allow you to build audiences based on user eligibility to an [introductory offer](https://docs.purchasely.com/docs/understanding-offer-types#introductory-offer)
  * Intro Offer Eligible Plans
  * Intro Offer Eligible Products

## Breaking Changes:

* iOS 12 minimum required 
* Removed `ONESIGNAL_PLAYER_ID` attribute.
* Replaced `UIListener` with [UIHandler](https://docs.purchasely.com/docs/ui-handler-dialogs).

## Android only

> 📘 Android 5.0 support extended
>
> We reverted our change with version 5.0.1 to support min SDK 21 again (Android 5.0).\
> **Please note** that Google [recently stated](https://support.google.com/googleplay/answer/9037938) that **Google Play Services supports only Android 6.0 and up**. As such, In-App purchases that are part of Google Play Services, may not work properly on devices below Android 6.0 (SDK 23).

* **Kotlin Updated**: Upgraded to Kotlin 2.0.20.
* **Updated Android Build Requirements**:
  * `compileSDK`: 34
  * `minSDK`: 21
* Updated purchase history retrieval:
  * Removed `purchaseHistory(onSuccess, onError)`.
  * Use `purchaseHistory(): List<PLYPlan>` instead.
* Updated subscriber status check:
  * Removed `isPastSubscriber(result: (Boolean) -> Unit)`.
  * Use `isPastSubscriber(): Boolean` instead.
* Renamed `PLYPresentationViewProperties` to `PLYPresentationProperties`.
* Replaced `show/hide closeButton` by `show/hide headerButton`
* Simplified Presentation API:
  * Removed `FetchPresentationForPlacement`.
  * Use `FetchPresentation` instead.
* Fixed an issue with user attribute `has expired subscription` that could not have been computed on SDK start callback
