3 steps are needed to create a new App in the Purchasely Console:

1. The configuration of the basic parameters: App name | default language | default dashboard currency | default integration currency | (+ app icon optionally)
2. The connection with the App stores (+ Stripe optionally)
3. The connection of the webhook (optional)

Once you've saved your application, the Console will provide you with the API key, that you will need to start the SDK.
