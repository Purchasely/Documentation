## What does this integration do?

It forwards your web funnel events to the ad platform so campaigns can be measured and optimized.

## Which events are forwarded?

Page View, Screen Viewed, Purchase Tapped and Purchase — toggle each one under **Front events**.

## Does it track in-app events too?

No. These run on the web funnel only; in-app tracking is configured separately in your app settings.

## Where do I find my IDs?

- Meta: [Pixel ID](https://www.facebook.com/business/help/952192354843755) and [Conversions API token](https://developers.facebook.com/docs/marketing-api/conversions-api/get-started)
- Google Ads: [Conversion ID & label](https://support.google.com/google-ads/answer/6095821)
- TikTok: [Pixel ID](https://ads.tiktok.com/help/article/get-started-pixel)
- X: [Pixel ID](https://business.x.com/en/help/campaign-measurement-and-analytics/conversion-tracking-for-websites.html)
