# Integration

To integrate Purchasely with your Segment account please follow the instructions below:

1. In your Segment dashboard, click on Add a new source
2. [block:image]{"images":[{"image":["https://files.readme.io/9c836a9-image.png",null,""],"align":"center","border":true}]}[/block]

   In the upcoming screen, Select the `“HTTP API”`

   [block:image]{"images":[{"image":["https://files.readme.io/9303311-image.png",null,""],"align":"center","border":true}]}[/block]
3. Provide the name of your source
4. [block:image]{"images":[{"image":["https://files.readme.io/0a4992e-image.png",null,""],"align":"center","border":true}]}[/block]

   Copy the Segment Write Key as shown in the screenshot below

   [block:image]{"images":[{"image":["https://files.readme.io/ccf59b6-image.png",null,""],"align":"center","border":true}]}[/block]
5. In the Purchasely console, go to **"External integrations"** section, and open the edition form for Segment

[block:image]{"images":[{"image":["https://files.readme.io/5bb010a-Capture_decran_2024-07-23_a_15.52.50.png",null,null],"align":"center","border":true}]}[/block]

6. Enable the integration and set your Android/iOS `API key`
