Purchasely is a SaaS platform empowering subscription apps.

It helps mobile organisations:

1. swiftly build their subscription stack by streamlining In-App Purchase integration with the major app stores (Apple App Store, Google Play Store, Huawei AppGallery, Amazon App store) and web payment platform (Stripe)
2. run seamless growth experiments without involving developers and creating a new version of the app, thanks to a set of no-code tools (no-code native paywall & screen builder, A/B tests, audience targeting, 3rd party integrations with most of the analytics, MMP and mCRM platforms)
3. measure and optimize their conversion, engagement and retention KPIs to increase their revenue

It is composed of: 

1. **a mobile SDK,** available in Swift, Kotlin, Objective-C, Java, ReactNative, Flutter, Cordova & Unity, that needs to be integrated to the mobile app
2. **a robust backend** that can be used as a subscription infrastructure
3. **a web Console** to craft visually appealing in-app user journeys, run campaigns and access a comprehensive set of analytics
