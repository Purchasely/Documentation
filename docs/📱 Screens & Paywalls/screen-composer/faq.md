# General Overview

Adding an FAQ section in a paywall is an excellent way to address user concerns and boost subscription rates by providing clarity and transparency.

# Benefits of FAQ

- **Reduces Friction and User Hesitation**: FAQs preemptively answer questions users may have before committing to a subscription.
- **Enhances Transparency and Credibility**: Including details about refunds, cancellations, and billing cycles demonstrates that you value user clarity and are upfront about your policies.
- **Saves Time for Customer Support**: By answering common questions upfront, you reduce the volume of inquiries to customer support teams.

1. _**Settings:**_ In this section, you can give the ID to the FAQ.  
   Id: the default value "faq_1" works fine. Change the ID only if you want to have several FAQs on the same Screen:  
   FAQs on a same Screen which are are mapped with the same Id interact together.  
   FAQs with different Ids are independent.
2. **_Styles_**: You can change the background color and border color and corner radius of the FAQ block. 
3. **_Layout_**: You can adjust the vertical spacing, height collapsed and expanded.
