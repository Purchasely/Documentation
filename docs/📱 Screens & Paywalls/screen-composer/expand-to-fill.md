The **Expand to fill** option allows the component to occupy the available space in a **Fill-height layout**. This helps fill the screen without manually adjusting the padding and margins of each component.

The expand to fill option is available with the components like image, video, Lottie, Carousel, Reviews, Countdown, Bulleted List, Spacer, Timeline vertical. The components which can expand to fill or shrink to fit will have a double headed vertical arrow.

If you expand a component to fill you can later shrink to fit based on your design requirement. This option is possible only with the Fill height layout.
