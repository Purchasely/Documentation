The usual process of conception of flows and paywalls usually starts in Figma where designers and product managers iterate before deciding to publish it. Purchasely offers the best tool to rebuild these screens in No Code in a tool close to Figma but it feels like an extra step no?

This is why we are releasing a Figma plugin that turns design into fully interactive screens that you can publish in seconds.

<br />

<br />

A screen is not just an interactive design. A quizz or a plan picker has different states (selected or unselected), they interact with each other and this goes far beyond a static design.
To be able to turn your Figma design into a real usable screen in Purchasely we allow you to manually map components to make the export directly usable.
 

For quizzes or plan pickers, if your design shows both items selected and unselected, type them both. That way the design will be applied directly. The first selected and first unselected items will be used to design the entire quizz / picker.
