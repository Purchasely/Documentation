# Still stuck?

* **A Screen does not render as expected** → use the [Screen Issue Report Template](screen-issue-report-template) so support can reproduce it on the first pass.
* **Something is wrong in your integration** → turn on [Debug Mode](debug-mode) on the device first, it exposes the SDK version, user IDs, Placement, Audience, A/B test and variant actually applied.
* **Anything else** → contact your Purchasely support channel with your app name, SDK version, platform and environment (production or sandbox).
